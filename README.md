### 🏗️ Engineering Pillars

#### 1. Infrastructure & Cloud Systems
- **Linux Server Administration**: Deployment, hardening, and maintenance of Ubuntu, Debian, and AlmaLinux environments.
- **Web Hosting Platforms**: Production management of LiteSpeed Enterprise, CloudLinux CageFS, cPanel/WHM, and reverse proxies (Nginx/Apache).
- **Storage & Synchronization**: Automated multi-destination backup pipelines leveraging Rclone and S3-compatible cloud object storage.

#### 2. Network Architecture & Routing
- **MikroTik RouterOS Routing**: Enterprise and SOHO network design using RouterBOARD hardware.
- **Traffic Engineering**: Bandwidth management via Hierarchical Token Bucket (HTB) Queue Trees, multi-WAN load balancing, and failover routing.
- **Network Security**: Stateful firewall filtering, port forwarding, VLAN isolation, and secure VPN tunnels (WireGuard, OpenVPN, L2TP/IPsec).

#### 3. Full-Stack Software Engineering
- **Modern Web Interfaces**: Component-driven, responsive web applications built with React, TypeScript, Next.js, and Tailwind CSS.
- **Backend Architecture**: Lightweight, high-throughput REST APIs written in PHP and Node.js.
- **Data Persistence**: Relational schema design and query optimization for MySQL and PostgreSQL; embedded zero-configuration persistence using SQLite in WAL (`Write-Ahead Logging`) mode.
- **Client-Side Architecture**: In-browser computing and telemetry tools running entirely client-side without external server data collection.

#### 4. Media Processing & Audio Systems
- **Web Video Transcoding**: Automated batch video transcoding pipelines, multi-threaded audio conversion scripts, and stream optimization for web playback.
- **Live Sound Engineering**: Multi-channel digital/analog mixer routing, parametric EQ tuning, speaker crossover alignment, and real-time acoustic feedback elimination.
- **Visual Production**: Color grading in Adobe Lightroom, video post-production in Adobe Premiere Pro, and 3D motion graphics.
